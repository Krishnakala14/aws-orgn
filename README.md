# AWS Organization and RBAC Lab

## Overview
This lab exercise involves setting up an AWS Organization with Role-Based Access Control (RBAC) using AWS IAM. The goal is to learn how to manage users, roles, and policies in a cloud environment without incurring costs.

## Objectives
- Create an AWS Organization using the free tier.
- Configure IAM roles and policies for RBAC.
- Test user permissions to ensure proper access control.
- Document the process for future reference.

## Steps Followed
1. **AWS Organization Setup:**  
   - Created a new organization in AWS.
   - Enabled all features for full management capabilities.
2. **IAM Configuration:**  
   - Created IAM policies and roles.
   - Set up IAM users with appropriate permissions.
3. **Testing and Validation:**  
   - Verified access restrictions using the IAM Policy Simulator.
   - Documented the process with screenshots.

## Outcome and Learning Points
- Understanding of AWS Organizations and centralized management.
- Practical experience with IAM policies and RBAC.
- Ability to troubleshoot and test cloud security configurations.
